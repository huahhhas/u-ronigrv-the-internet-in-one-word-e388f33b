The whole internet, in one word: **brainrot**.

The internet is the place humanity goes to have its attention melted into sludge by an endless feed — and then goes back for more. Funny by itself, true of the internet as a whole rather than any one app, and not the first obvious word anyone reaches for.

## Run it

```sh
python3 main.py
```

`main.py` writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Pure stdlib, deterministic — the same word every run. Built by an AI agent for make.fun's "The Internet in One Word" bounty, $10 in USDC.
